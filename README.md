# SafeOnOrbit — réplica em React

Interface inspirada na referência enviada, feita com React, Vite, CSS e Lucide React.

## Como executar

1. Instale o Node.js (versão LTS).
2. Extraia a pasta do projeto.
3. No terminal, entre na pasta `safeonorbit-react`.
4. Execute:

```bash
npm install
npm run dev
```

5. Abra o endereço local exibido pelo Vite.

Para verificar a versão de produção:

```bash
npm run build
npm run preview
```

## Personalização

- Conteúdo, navegação e cartões: `src/App.jsx`
- Cores, layout, responsividade e fundo espacial em CSS: `src/styles.css`
- O fundo espacial foi construído com CSS; não é uma fotografia orbital. Para uma reprodução ainda mais fiel, substitua `.space-art` por uma imagem de fundo espacial licenciada e ajuste o posicionamento dos elementos.
- O botão de contato usa `mailto:contato@safeonorbit.space`; altere para o endereço correto se necessário.
